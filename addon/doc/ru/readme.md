## Введение

Дополнение **FavoriteLinks** — это инструмент для организованного и эффективного управления вашими любимыми ссылками. Оно позволяет сохранять, редактировать и удалять ссылки в категоризированном списке, предлагая интуитивно понятный интерфейс с такими функциями, как добавление новых ссылок, переименование заголовков, удаление ненужных записей и управление категориями. Кроме того, дополнение позволяет импортировать закладки непосредственно из файлов HTML, экспортируемых браузерами.

При запуске дополнения вы получаете быстрый доступ к своим ссылкам и можете открывать их непосредственно в браузере по умолчанию. Теперь также поддерживается открытие ссылок во вторичном браузере, если вам нужна большая гибкость.

## Установка

Для установки дополнения **FavoriteLinks** в NVDA выполните следующие действия:

1. В NVDA, откройте меню **инструментов** и перейдите в **магазин дополнений**.
2. На вкладке **Доступных дополнений** перейдите к полю **Поиска**.
3. Ищите "favoriteLinks". В результатах поиска нажмите **Enter** или **Применить**, а затем выберите **Установить**.
4. Перезапустите NVDA для применения изменения.

## Конфигурация

Вы полностью контролируете место сохранения ваших ссылок и браузер, который их открывает.

1. Откройте меню NVDA: `NVDA+N` > *Параметры* > *Настройки*.
2. В списке категорий выберите **Избранные ссылки**.

Вы можете выбрать пользовательское местоположение для сохранения файла ссылок, используя кнопку **"Выберите или добавьте папку"** (`Alt+В`).

Для определения дополнительного браузера, который может быть как установленным, так и переносным:

1. Перейдите с помощью клавиши `Tab` к полю **Путь к браузеру**.
2. Используйте кнопку **"Выбрать путь к браузеру"** (`Alt+Б`) для добавления исполняемого файла нужного браузера.

## Использование

### Доступ к Дополнению

* Нажмите `Alt+Windows+K`.
* Или получите доступ через `NVDA+N` > *Инструменты* > *Избранные Ссылки*.

### Главный интерфейс

Главный интерфейс состоит из двух основных полей, навигация по которым осуществляется с помощью клавиши `Tab`:

1. **Категория**: Комбинированный список с существующими категориями.
2. **Список Ссылок**: Список, отображающий ссылки, связанные с выбранной категорией.

Для доступа к дополнительным параметрам воспользуйтесь **контекстным меню** (клавиша контекст) в любом из этих полей.

### Доступные Действия

#### В комбинированном списке категорий

* **Добавить Категорию**: Создаёт новую категорию.
* **Редактировать Категорию**: Переименовывает выбранную категорию.
* **Удалить Категорию**: Удаляет категорию и все её ссылки.
* **Экспорт Ссылок**: Сохраняет все ссылки и категории в файл `.json`.
* **Импорт Ссылок**: Загружает ссылки и категории из файла `.json`.

#### В списке ссылок

* **Открыть Ссылку**: Открывает ссылку в настроенном вами браузере.
> **Примечание**: Необходимо предварительно настроить дополнительный браузер в параметрах.
* **Добавить Ссылку**: Позволяет вставить новый URL. Название будет получено автоматически, но вы можете ввести его вручную, если получение не удастся.
* **Редактировать Ссылку**: Изменяет название и URL существующей ссылки.
* **Удалить Ссылку**: Удаляет выбранную ссылку.
* **Экспорт Ссылок** / **Импорт Ссылок**: Аналогично вариантам категорий.
* **Импорт закладок HTML**: Импортирует ссылки из файла `.html`, экспортированного браузерами.
* **Сортировать Ссылки**: Упорядочивает ссылки текущей категории по алфавиту.

### Импорт закладок HTML

FavoriteLinks также позволяет импортировать закладки непосредственно из файлов HTML, например, экспортированных браузерами (Chrome, Firefox, Edge и другими).

Эта возможность полезна для быстрого и упорядоченного переноса существующих закладок в дополнение.

#### Как импортировать закладки из файла HTML

1. Откройте дополнение **Избранные ссылки**.
2. Воспользуйтесь контекстным меню **комбинированного списка категорий** или пунктом в главном меню.
3. Выберите **Импорт закладок HTML**.
4. Выберите файл `.html`, экспортированный из вашего браузера.
5. Дождитесь обработки ссылок.

Во время импорта:

* Ход работы отображается в виде индикатора выполнения.
* Вы можете **отменить операцию в любое время**.
* NVDA оперативно реагирует на запросы на протяжении всего процесса.

#### Организация импортированных ссылок

* Импортированные ссылки автоматически добавляются в файл JSON, указанный в настройках дополнения.
* По умолчанию, закладки вставляются в категорию **“Импортированные закладки”**.
* Повторно не добавляются дублирующиеся ссылки (с одинаковым URL).

По завершении импорта отображается сообщение с подтверждением, и интерфейс дополнения автоматически обновляется.

### Горячие клавиши

| Функция | Горячая клавиша |
| :--- | :--- |
| Открыть ссылку | `Alt+О` или `Enter` (в списке ссылок) |
| Добавить ссылку | `Alt+Д` |
| Добавить категорию | `Alt+Г` |
| Редактировать ссылку | `Alt+Р` или `F2` |
| Удалить ссылку | `Alt+А` или `Del` |
| Сохранить URL текущей страницы | `Shift+Control+D` |
| Показать URL текущей страницы | `Windows+Control+P` Двойное нажатие копирует URL в буфер обмена. |
| Выход | `Alt+Ы`, `Esc` или `Alt+F4` |

## Диалог "Добавить Новую Ссылку"

1. **Категория**: Выберите нужную категорию.
2. **URL**: Вставьте или введите адрес ссылки.
> Если вы уже скопировали URL, он будет вставлен автоматически.
3. **ОК (`Alt+О`)**: Добавляет ссылку.
> Название будет получено автоматически. Если получение не удастся, вы сможете ввести его вручную.
4. **Отмена (`Alt+Т`)**: Закрывает диалог. `Esc` или `Alt+F4` также работают.

## Диалог "Редактировать Ссылку"

1. **Категория**: При изменении категории здесь ссылка будет перемещена в новую категорию.
2. **Название**: Отредактируйте название ссылки.
3. **URL**: Измените адрес ссылки.
4. **ОК (`Alt+О`)**: Сохраняет изменения.
5. **Отмена (`Alt+Т`)**: Закрывает без сохранения. `Esc` или `Alt+F4` также работают.
